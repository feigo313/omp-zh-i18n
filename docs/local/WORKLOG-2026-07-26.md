## Phase 2a 发行就绪审查（2026-07-26 补充）

### R1: 中文 JSON 加载验证

三种分发路径均确认加载 zh 翻译，无阻塞：

| 路径 | zh 加载 | 机制 |
|------|---------|------|
| 源码运行 | 是 | `fs.readdir` 读取 `src/i18n/lang/zh-*.json` |
| npm 包 | 是 | `EMBEDDED_TRANSLATIONS` 静态导入兜底（`dist/lang/` 在 npm 包中不存在，但嵌入式翻译覆盖） |
| 编译二进制 | 是 | `EMBEDDED_TRANSLATIONS`（bun --compile 内联静态导入） |

**语言检测差异**（非阻塞）：`prompt-loader.ts:75-90` 的 `detectLanguage()` 检查 `OMP_LANG` + `LANG` 环境变量，但不读 `config.yml`。主 i18n 系统读 `config.yml`。用户通过设置切换语言后，prompt 翻译可能仍为英文（若 `LANG` 未设为 zh）。
