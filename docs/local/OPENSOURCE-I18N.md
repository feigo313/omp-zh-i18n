# 中文 i18n 开源说明（拟 README 片段）

> 可复制到 GitHub 仓库 README / 发布说明。  
> 更新：2026-07-24

## 这是什么

Oh My Pi（`omp`）中文界面语言包与本地维护脚本，基于设置 schema / EN 文案对齐，覆盖欢迎页、设置一二级/三级选项等。

## 版本策略（重要）

- **不会**承诺跟随官方 **每一个** 小版本即时更新。  
- 汉化维护为 **不定期**：在人力允许时对照上游新版本补 key、补二级/三级菜单说明。  
- 官方 `omp` 升级后，设置里可能出现**英文回退**（缺 key 时显示 schema 原文），属预期现象。

## 你可以怎么用

1. **直接使用本仓库某一版**语言包 / 改过的 `lang`（或后续提供的安装脚本）。  
2. **有能力自行跟版**（推荐进阶用户）：  
   - 对照上游 release 的 `en-settings-*.json` / `settings-schema.ts` 与 options 源（如 `service-tier.ts`、`stt/*`、`tiny/models.ts`）  
   - 用仓库内 realign / schema 检查脚本扫 missing  
   - 只译用户可见说明；品牌/模型 id 可保留英文  
3. **欢迎 PR**：补译、跟版 diff、安装脚本均可。

## 不承诺

- 与官方同日发布  
- 100% 无英文残留（枚举 id、品牌名、技术型号可保留）  
- 替代官方安装渠道（完整二进制发行另论）

## 反馈

Issue 请注明：omp 版本、界面路径（如「设置 → 模型 → 采样 → 服务层级」）、截图或 key 名。
